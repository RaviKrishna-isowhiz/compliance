DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════════

Tables (7):
  1. compliance_frameworks - Framework definitions
  2. compliance_questions - Assessment questions
  3. project_compliance_assessments - Assessment records
  4. framework_compliance_status - Status tracking
  5. compliance_responses - User responses
  6. compliance_evidence - Document storage metadata
  7. compliance_audit_log - Activity audit trail

Relationships:
  • Frameworks → Questions (1:many)
  • Assessments → Framework Status (1:many)
  • Framework Status → Responses (1:many)
  • Responses → Evidence (1:many)
  • Assessments → Audit Log (1:many)
